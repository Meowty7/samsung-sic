## Glosario

**diccionario (dict)**: tipo de datos formado por pares clave-valor entre llaves, que permite obtener un valor a partir de su clave.
**clave**: elemento que identifica un valor dentro del diccionario; debe ser única y no se puede obtener a partir del valor.
**valor**: dato asociado a una clave; puede repetirse y ser de cualquier tipo.
**enfoque clave y asignación**: uso de la clave para leer, insertar o modificar valores, con `d[clave]` y `d[clave] = valor`.
**KeyError**: error que se produce al leer o borrar una clave que no existe en el diccionario.
**JSON**: formato de texto, independiente del lenguaje, para intercambiar datos formados por pares clave-valor.
**json.loads**: función del módulo json que convierte una cadena con formato JSON en un diccionario de Python.
**format**: método de cadenas que reemplaza marcadores `{}` por valores y controla ancho y decimales.

## Quiz

P: Dado person = {'Name': 'David Doe', 'Age': 26, 'Weight': 82}, ¿qué devuelve 'David Doe' in person?
A) True
B) False
C) 'Name'
D) Lanza KeyError
Correcta: B
Por qué: el operador in comprueba solo las claves, y 'David Doe' es un valor.
Referencia: PDF parte 1, pág. 115

P: ¿Qué ocurre al ejecutar del person['Hometown'] si esa clave no existe?
A) Se ignora la instrucción
B) Se agrega la clave con valor None
C) Se produce IndexError
D) Se produce KeyError
Correcta: D
Por qué: borrar o leer una clave que no existe en un diccionario lanza KeyError.
Referencia: PDF parte 1, pág. 112

P: ¿Qué hace person['Age'] = 27 si 'Age' ya existe en el diccionario?
A) Agrega un segundo elemento 'Age'
B) Modifica el valor asociado a 'Age'
C) Lanza KeyError
D) Lanza TypeError
Correcta: B
Por qué: las claves son únicas, así que asignar a una clave existente reemplaza su valor; si no existiera, la insertaría.
Referencia: PDF parte 1, pág. 110

P: Si d1 = {'Name': 'David Doe', 'Age': 26} y d2 = {'Age': 26, 'Name': 'David Doe'}, ¿qué devuelve d1 == d2?
A) False, porque el orden es distinto
B) True, porque tienen los mismos elementos
C) Lanza TypeError
D) None
Correcta: B
Por qué: == compara el contenido de los diccionarios sin tener en cuenta el orden de los pares.
Referencia: PDF parte 1, pág. 116

P: ¿Qué devuelve json.loads('{"Name": "David Doe", "Married": true}')?
A) Una cadena con el mismo texto
B) Una lista con dos elementos
C) Un diccionario donde Married vale True
D) Un archivo llamado Name.json
Correcta: C
Por qué: loads convierte la cadena JSON en un diccionario de Python y true pasa a ser True.
Referencia: PDF parte 1, págs. 122–123

P: ¿Qué imprime print('{0:10.3f}'.format(3.1415926))?
A) 3.142 con 10 posiciones y alineado a la derecha
B) 3.1415926
C) 3.14
D) 0003.142 con ceros a la izquierda
Correcta: A
Por qué: 10 es el ancho total del campo y .3f los tres decimales, de modo que se imprime '     3.142'.

## Errores comunes

- Leer o borrar una clave inexistente: KeyError (se evita con `clave in dic`).
- Creer que `valor in diccionario` busca entre los valores: solo mira las claves.
- Repetir una clave esperando conservar ambos valores: queda solo el último.
- Pensar que dic.pop(0) borra el primer elemento por posición: borra la clave 0 y los demás valores no se mueven.
- Comparar diccionarios con >, <, >= o <=: produce TypeError.
- Usar comillas simples en una cadena JSON (JSONDecodeError) o confundir load/dump (archivos) con loads/dumps (cadenas).
