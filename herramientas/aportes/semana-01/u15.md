## Glosario

**fromkeys**: método `dict.fromkeys(claves, valor)` que crea un diccionario con las claves dadas y un mismo valor inicial (None por defecto).
**defaultdict**: diccionario del módulo `collections` que crea automáticamente un valor por defecto para las claves ausentes.
**función generadora de valor por defecto**: función sin argumentos (int, list...) que se pasa a `defaultdict` para producir el valor inicial.
**diccionario doble (anidado)**: diccionario cuyos valores son otros diccionarios, accesible con `d[clave1][clave2]`.
**copia superficial**: `x.copy()` duplica solo el primer nivel; los objetos interiores se siguen compartiendo.
**copia profunda**: `copy.deepcopy(x)` duplica todos los niveles en memoria independiente.
**módulo**: archivo de Python con funciones, variables o clases que se carga con `import`.
**epoch**: instante de referencia del sistema Unix (1 de enero de 1970, 0:0:0 UTC) desde el que `time.time()` cuenta segundos.

## Quiz

P: ¿Qué devuelve `dict.fromkeys(['a', 'b'])`?
A) {'a': 0, 'b': 0}
B) {'a': None, 'b': None}
C) ['a', 'b']
D) KeyError
Correcta: B
Por qué: sin segundo argumento, todos los valores se inicializan a None.
Referencia: PDF parte 2, págs. 79–80

P: Con `y = defaultdict(int)`, ¿qué devuelve `y['z']` si 'z' no existe?
A) KeyError
B) None
C) ''
D) 0
Correcta: D
Por qué: defaultdict llama a int(), cuyo valor por defecto es 0, y crea la clave.
Referencia: PDF parte 2, págs. 82–83

P: ¿Qué obtiene el bucle `for i in x:` si `x` es un diccionario?
A) Solo las claves
B) Solo los valores
C) Tuplas (clave, valor)
D) Los índices numéricos
Correcta: A
Por qué: recorrer un diccionario entrega sus claves; para pares se usa x.items().
Referencia: PDF parte 2, pág. 87

P: Si `x = {'a': 0}` e `y = x`, ¿qué muestra `x is y`?
A) False
B) True
C) 0
D) Error
Correcta: B
Por qué: la asignación no copia; ambas variables apuntan al mismo objeto.
Referencia: PDF parte 2, pág. 93

P: Dado `x = {'a': {'python': '2.7'}}`, ¿cómo se copia de forma que cambiar la copia no afecte a x?
A) y = x
B) y = x.copy()
C) y = copy.deepcopy(x)
D) y = dict(x)
Correcta: C
Por qué: copy y dict(x) copian solo el primer nivel; deepcopy duplica también los diccionarios interiores.
Referencia: PDF parte 2, págs. 97–98

P: ¿Por qué `math.sin(90.0)` no devuelve 1?
A) Porque sin solo acepta enteros
B) Porque devuelve el coseno
C) Porque el ángulo se interpreta en radianes
D) Porque falta importar time
Correcta: C
Por qué: las funciones trigonométricas de math usan radianes; para 90 grados hay que usar math.pi / 2 o math.radians(90).
Referencia: PDF parte 2, pág. 121

## Errores comunes

- Reasignar la variable (`y = defaultdict(int)`) tras crear otro diccionario y perder los datos anteriores.
- Creer que `y = x` crea un diccionario nuevo: ambos nombres comparten el mismo objeto.
- Usar `copy()` con diccionarios dobles y esperar que los diccionarios interiores sean independientes.
- Pasar grados a `math.sin`, `math.cos` o `math.tan`, que esperan radianes.
- Escribir direcciones con espacios cuando el código hace `adr, review = input().split()`: provoca `ValueError`.
- Consultar `y['z']` en un `defaultdict` pensando que no cambia nada: inserta la clave `'z'`.
