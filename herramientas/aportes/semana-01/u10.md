## Glosario

**lista**: estructura de datos mutable que guarda varios elementos, de cualquier tipo, bajo un solo nombre, entre corchetes y separados por comas.
**índice**: número que indica la posición de un elemento; en una lista de n elementos va de 0 a n-1 (o de -1 a -n con índices negativos).
**indexación**: acceso al valor de un elemento mediante su índice de posición, por ejemplo `lista[0]`.
**rebanado (slicing)**: operación `lista[inicio:fin:paso]` que crea una lista nueva con una sección de otra; el índice final no se incluye.
**tupla**: secuencia inmutable, parecida a la lista, que se crea con paréntesis y no admite cambios una vez creada.
**mutable / inmutable**: un tipo mutable (list, set, dict) puede modificarse tras crearse; uno inmutable (int, float, str, tuple) no.
**operadores in / not in**: devuelven True o False según un elemento esté o no en una secuencia (cadena, lista o tupla).
**método**: función propia de un objeto que se invoca con punto, como `lista.append(x)`.

## Quiz

P: Dada a_list = [10, 20, 30, 40, 50, 60, 70, 80], ¿qué devuelve a_list[1:5]?
A) [10, 20, 30, 40, 50]
B) [20, 30, 40, 50]
C) [20, 30, 40, 50, 60]
D) [10, 20, 30, 40]
Correcta: B
Por qué: el rebanado incluye el índice 1 y llega hasta el 4, porque el índice final (5) no se incluye.
Referencia: PDF parte 1, pág. 39

P: ¿Qué error se produce al ejecutar n_list[6] si n_list = [11, 22, 33, 44, 55, 66]?
A) ValueError
B) TypeError
C) IndexError
D) KeyError
Correcta: C
Por qué: la lista tiene índices de 0 a 5, y usar un índice fuera de ese rango lanza IndexError.
Referencia: PDF parte 1, pág. 27

P: Si list1 = [11, 22, 33, 44], ¿cuál es el resultado de list1.append([55, 66])?
A) [11, 22, 33, 44, 55, 66]
B) [11, 22, 33, 44, [55, 66]]
C) [55, 66, 11, 22, 33, 44]
D) Se produce un error
Correcta: B
Por qué: append agrega un único elemento, que aquí es la lista completa; para agregar cada elemento se usa extend.
Referencia: PDF parte 1, pág. 33

P: ¿Qué ocurre al ejecutar [11, 22, 33].remove(88)?
A) Devuelve None y no cambia la lista
B) Elimina el último elemento
C) Lanza ValueError porque 88 no está en la lista
D) Lanza IndexError
Correcta: C
Por qué: remove busca el valor y, si no existe, lanza ValueError; se evita comprobando antes con 88 in lista.
Referencia: PDF parte 1, pág. 38

P: ¿Cuál de los siguientes tipos es inmutable?
A) list
B) dict
C) set
D) tuple
Correcta: D
Por qué: la tupla no se puede modificar tras crearse; intentar t1[0] = 100 produce TypeError.
Referencia: PDF parte 1, págs. 56–58

P: ¿Qué devuelve a_list[::-1]?
A) La lista sin su último elemento
B) Solo los dos primeros elementos
C) Los elementos de dos en dos
D) Todos los elementos en orden inverso
Correcta: D
Por qué: con paso -1 y sin inicio ni fin, el rebanado recorre toda la lista de atrás hacia adelante.
Referencia: PDF parte 1, pág. 45

## Cheatsheet

lista = [87, 84, 95]  # crea una lista
lista[0], lista[-1]  # primer y último elemento
len(lista), max(lista), min(lista), sum(lista)  # longitud, máximo, mínimo y suma
lista.append(x)  # agrega un elemento al final
lista.extend([x1, x2])  # agrega cada elemento de otra lista
lista.insert(i, x)  # inserta x en la posición i
del lista[i]  # borra por posición (instrucción, no método)
lista.pop(i)  # borra por posición y devuelve el elemento
lista.remove(x)  # borra el primer elemento igual a x
x in lista, x not in lista  # comprueba pertenencia
lista[inicio:fin:paso]  # rebanado; fin no se incluye
lista[::-1]  # lista en orden inverso
lista.sort(reverse=True)  # ordena en el lugar, descendente
colores = ("red", "green")  # tupla inmutable
a, b = (1, 2)  # asignación múltiple con una tupla

## Errores comunes

- Usar un índice igual o mayor que len(lista): produce IndexError.
- Llamar a remove con un valor ausente (ValueError) sin comprobar antes con `in`.
- Confundir append([a, b]) (agrega una lista anidada) con extend([a, b]).
- Creer que lista[1:5] incluye el índice 5: el índice final no se incluye.
- Intentar modificar una tupla con tupla[0] = x: produce TypeError.
- Escribir lista = lista.sort(): sort modifica la lista y devuelve None.
