## Glosario

**objeto secuencia**: objeto creado a partir de un tipo de dato de secuencia (lista, tupla, rango o cadena); cada valor que contiene se llama elemento.
**operador de pertenencia**: `in` y `not in`; devuelven `True` o `False` según el elemento esté o no en la secuencia.
**vinculación (enlace)**: unir dos secuencias del mismo tipo con el operador `+`, que crea un objeto nuevo; no funciona con `range`.
**iteración con `*`**: repetir una secuencia con `secuencia * entero`; el multiplicador debe ser un entero y `range` no lo admite.
**índice**: número que indica la posición de un elemento; va de 0 a n-1, o de -1 a -n si es negativo.
**corte (slicing)**: `secuencia[inicio:fin]`, que extrae una porción incluyendo `inicio` y excluyendo `fin`.
**tupla**: secuencia inmutable; con un solo elemento necesita coma, como en `(100,)`.
**empaquetado y desempaquetado**: juntar valores en una variable (`a = (1, 2)`) y repartirlos en varias (`x, y = c`).

## Quiz

P: ¿Qué devuelve `11 in range(10)`?
A) True
B) False
C) TypeError
D) 10
Correcta: B
Por qué: `range(10)` produce de 0 a 9, de modo que el 11 no pertenece a la secuencia.
Referencia: PDF parte 1, pág. 162

P: ¿Qué ocurre al ejecutar `range(10) + range(10, 20)`?
A) Devuelve un rango de 0 a 19
B) Devuelve una lista de 0 a 19
C) Lanza TypeError
D) Devuelve una tupla de 0 a 19
Correcta: C
Por qué: el operador `+` no puede enlazar objetos `range`; hay que convertirlos antes con `list` o `tuple`.
Referencia: PDF parte 1, pág. 165

P: ¿Cuál de estas expresiones lanza un error?
A) `[11, 22] * 2`
B) `(1, 2, 3) * 2`
C) `'hello' * 3`
D) `[11, 22] * [55, 66]`
Correcta: D
Por qué: la multiplicación solo acepta `secuencia * entero`; no se pueden multiplicar dos secuencias.
Referencia: PDF parte 1, pág. 170

P: Dada `datos = [10, 20, 30, 40, 50, 60, 70, 80]`, ¿qué devuelve `datos[-7:-2]`?
A) [20, 30, 40, 50, 60]
B) [20, 30, 40, 50, 60, 70]
C) [10, 20, 30, 40, 50]
D) [30, 40, 50, 60, 70]
Correcta: A
Por qué: -7 es el índice del 20 y el final -2 (el 70) se excluye, así que termina en el 60.
Referencia: PDF parte 1, pág. 184

P: ¿Cuál es el tipo de `tup = (100)`?
A) tuple
B) list
C) int
D) range
Correcta: C
Por qué: sin coma, los paréntesis solo agrupan y Python lo interpreta como el entero 100; la tupla sería `(100,)`.
Referencia: PDF parte 1, pág. 197

P: ¿Cómo se ordena una tupla `tup`, dado que no tiene método `sort`?
A) `tup.sort()`
B) Se convierte con `list(tup)`, se aplica `sort` y se obtiene la lista ordenada
C) `tup.sorted()`
D) `tup[:] = sorted(tup)`
Correcta: B
Por qué: la tupla es inmutable, por lo que se convierte a lista (mutable) y se ordena ahí.
Referencia: PDF parte 1, pág. 203

## Cheatsheet

```
x in secuencia  # True si x es un elemento (en cadenas busca subcadenas)
x not in secuencia  # True si x no está
a + b  # enlaza secuencias del mismo tipo (no sirve con range)
secuencia * 3  # repite la secuencia 3 veces (el multiplicador es un entero)
secuencia.count(x)  # número de apariciones de x
len(secuencia)  # número de elementos
secuencia[0]  # primer elemento (índices de 0 a n-1)
secuencia[-1]  # último elemento
secuencia[1:5]  # elementos de los índices 1 a 4
secuencia[:-2]  # todo salvo los dos últimos
list(range(2, 11, 2))  # [2, 4, 6, 8, 10]
ord('C')  # 67, código ASCII del carácter
t = (100,)  # tupla de un elemento (la coma es obligatoria)
a, b = b, a  # intercambia dos valores
tuple(sorted(t))  # tupla ordenada (la tupla no tiene sort)
```

## Errores comunes

- Escribir `(100)` creyendo que es una tupla: es un entero. Hace falta la coma: `(100,)`.
- Usar `+` o `*` con `range` (`TypeError`): convertir antes con `list(...)` o `tuple(...)`.
- Multiplicar dos secuencias (`list1 * list2`): el multiplicador siempre debe ser un entero.
- Suponer que el corte incluye el índice final, o que el primer índice es 1.
- Intentar `tupla[0] = valor` o `tupla.sort()`: la tupla es inmutable.
- Acceder a `secuencia[len(secuencia)]`: el último índice es `len(secuencia) - 1`.
