## Glosario

**regla de ámbito (LEGB)**: orden en que Python busca un nombre: Local, Enclosing (función envolvente), Global y Built-in.
**variable local**: variable creada dentro de una función; existe solo durante la llamada y desaparece al terminar.
**variable global**: variable definida a nivel de módulo, fuera de las funciones; una función solo puede asignarla si declara `global`.
**función anidada**: función definida dentro de otra función; puede leer las variables de la función externa.
**función de primera clase**: función tratada como un objeto: se pasa como argumento, se asigna a una variable, se devuelve o se guarda en una lista.
**nonlocal**: palabra clave que enlaza un nombre con la variable del espacio de nombres envolvente más cercano (vinculación).
**clausura (closure)**: función anidada devuelta por la función externa que conserva las variables de esta aunque ya haya terminado.
**variable libre**: variable usada en un bloque que no es global ni está definida en ese bloque (por ejemplo, `a` dentro de `mult`).

## Quiz

P: ¿Cuál es el orden de búsqueda de la regla de ámbito de Python?
A) Global, Local, Enclosing, Built-in
B) Local, Enclosing, Global, Built-in
C) Built-in, Global, Enclosing, Local
D) Local, Global, Enclosing, Built-in
Correcta: B
Por qué: Python busca de adentro hacia afuera (LEGB) y se detiene en el primer ámbito donde aparece el nombre.
Referencia: PDF parte 2, pág. 17

P: Con `counter = 100` global, ¿qué imprime `counter` fuera de la función tras ejecutar `def f(): counter = 200` y llamar a `f()`?
A) 200
B) 0
C) 100
D) Lanza un error
Correcta: C
Por qué: la asignación dentro de la función crea una variable local con memoria separada; la global no cambia.
Referencia: PDF parte 2, págs. 20–21

P: ¿Para qué sirve la palabra clave `global` dentro de una función?
A) Para crear una variable local nueva
B) Para que la función use y modifique la variable global en lugar de crear una local
C) Para enlazar con la variable de la función envolvente más cercana
D) Para borrar una variable global
Correcta: B
Por qué: con `global counter`, cambiar el valor dentro de la función también cambia el valor fuera.
Referencia: PDF parte 2, págs. 23–24

P: ¿Qué ocurre si se declara `nonlocal x` en una función que no está anidada y solo existe una `x` global?
A) Se modifica la x global
B) NameError
C) SyntaxError: no binding for nonlocal 'x' found
D) Se crea una x local
Correcta: C
Por qué: `nonlocal` exige una variable en una función envolvente; la global no cuenta.
Referencia: PDF parte 2, pág. 35

P: ¿Cuáles son los usos principales de una clausura según el PDF?
A) Acelerar bucles y reducir el uso de memoria
B) Limitar el uso de variables globales y ocultar datos
C) Importar módulos y crear clases
D) Evitar el uso de funciones lambda
Correcta: B
Por qué: la clausura conserva el dato como variable local de la función externa, sin exponerlo como global.
Referencia: PDF parte 2, págs. 39–40

P: Con `c1 = makecounter(); c2 = makecounter()` (contador con `nonlocal count`), ¿qué imprimen `c1()`, `c1()` y `c2()` en ese orden?
A) 1, 1, 1
B) 1, 2, 3
C) 1, 2, 2
D) 1, 2, 1
Correcta: D
Por qué: cada llamada a makecounter crea una clausura con su propio `count`; c1 y c2 son independientes.

def f(): global x; x = 20  # modifica la variable global x
def g(): nonlocal v  # enlaza con v de la función envolvente más cercana
L -> E -> G -> B  # orden de búsqueda de nombres (regla LEGB)

return lambda x: a * x + b  # clausura escrita con lambda

## Errores comunes

- Creer que asignar dentro de una función modifica la variable global: crea una local si no se declara `global`.
- Dar a una variable el nombre de una función incorporada (`abs`, `list`, `sum`) y bloquearla; se arregla con `del`.
- Leer y asignar una variable sin `global`/`nonlocal`: `UnboundLocalError`.
- Usar `global` para una variable de la función exterior (`NameError`) o `nonlocal` para una global (`SyntaxError`).
- Devolver `mul_add()` en vez de `mul_add` al crear la clausura, o pasar `f()` en vez de `f` como argumento.
- Llamar a `re.search(...).group()` sin comprobar si el resultado es `None`.
