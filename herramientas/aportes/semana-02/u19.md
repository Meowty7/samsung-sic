## Glosario

**función lambda (expresión lambda)**: función anónima, sin nombre y de una sola expresión, escrita como `lambda parámetros: expresión`; devuelve el valor de la expresión.
**filter**: función incorporada que recibe una función y un iterable y devuelve solo los elementos para los que la función devuelve `True`.
**map**: función incorporada que aplica una función a cada elemento de un iterable y devuelve los resultados.
**reduce**: función del módulo `functools` que combina los elementos de un iterable, de izquierda a derecha, en un único valor.
**iterable**: objeto que se puede recorrer elemento a elemento, como una lista, una tupla, una cadena o un rango.
**iterador**: objeto que entrega un elemento cada vez con `next()` y lanza `StopIteration` cuando se agota; se obtiene con `iter()`.
**comprensión de listas**: sintaxis `[expresión for x in iterable if condición]` que crea una lista en una sola línea.
**excepción**: error que se produce al ejecutar el código y que se atiende con `try ... except`, con bloques opcionales `else` y `finally`.

## Quiz

P: ¿Qué devuelve (lambda x, y: x + y)(100, 200)?
A) Un error de sintaxis
B) 100200
C) 300
D) Una función
Correcta: C
Por qué: la lambda se define y se llama en la misma línea; recibe 100 y 200 y devuelve su suma.
Referencia: PDF parte 1, pág. 157

P: ¿Qué devuelve list(filter(lambda x: x >= 19, [34, 39, 20, 18, 13, 54]))?
A) [18, 13]
B) [34, 39, 20, 54]
C) [34, 39, 20, 18, 13, 54]
D) [True, True, True, False, False, True]
Correcta: B
Por qué: filter conserva los elementos para los que la lambda devuelve True; 18 y 13 quedan fuera.
Referencia: PDF parte 1, pág. 163

P: ¿Qué devuelve list(map(lambda x: x**2, [1, 2, 3, 4, 5, 6, 7]))?
A) [2, 4, 6, 8, 10, 12, 14]
B) [1, 8, 27, 64, 125, 216, 343]
C) [1, 4, 9, 16, 25, 36, 49]
D) [1, 2, 3, 4, 5, 6, 7]
Correcta: C
Por qué: map aplica la lambda a cada elemento y devuelve el cuadrado de cada uno.
Referencia: PDF parte 1, pág. 169

P: ¿Qué valor devuelve reduce(lambda x, y: x + y, [1, 2, 3, 4]) y de qué módulo se importa reduce?
A) 10, del módulo functools
B) 24, del módulo math
C) 10, del módulo itertools
D) [1, 3, 6, 10], de functools
Correcta: A
Por qué: reduce calcula (((1 + 2) + 3) + 4) = 10 y se importa con from functools import reduce.
Referencia: PDF parte 1, pág. 176

P: ¿Qué ocurre al llamar a next() sobre un iterador que ya devolvió todos sus elementos?
A) Devuelve None
B) Devuelve 0
C) Reinicia el iterador desde el principio
D) Lanza la excepción StopIteration
Correcta: D
Por qué: StopIteration es la señal de que no hay más elementos, y así es como el bucle for sabe cuándo terminar.
Referencia: PDF parte 1, pág. 195

P: En un bloque try - except - else - finally, ¿cuándo se ejecuta finally?
A) Solo si hubo una excepción
B) Solo si no hubo ninguna excepción
C) Siempre, haya o no excepción
D) Nunca si el except atrapó el error
Correcta: C
Por qué: finally se ejecuta independientemente de la excepción; else corre solo cuando no hubo ninguna.
Referencia: PDF parte 1, pág. 187

## Cheatsheet

lambda x, y: x + y  # función anónima que suma dos valores
(lambda x, y: x + y)(100, 200)  # define y llama la lambda a la vez (300)
add = lambda x, y: x + y  # lambda asignada a un nombre
filter(lambda x: x >= 19, ages)  # iterador con los elementos que cumplen la condición
list(filter(lambda x: x % 2 == 0, n_list))  # lista con los números pares
list(map(lambda x: x**2, a))  # lista con el cuadrado de cada elemento
list(map(int, "10 20 30".split()))  # convierte cadenas a enteros
from functools import reduce  # reduce vive en functools
reduce(lambda x, y: x + y, [1, 2, 3, 4])  # combina todo en un valor (10)
it = iter([10, 20, 30]); next(it)  # convierte en iterador y pide el siguiente elemento (10)
[x**2 for x in range(1, 8) if x % 2 == 1]  # comprensión de listas con condición
all([1, 2, 3]), any([0, 0, 1])  # True si todos son verdaderos; True si alguno lo es
try: ... except ZeroDivisionError: ... else: ... finally: ...  # manejo de excepciones completo
valid_date('1915.5.33')  # proyecto Sherlock: imprime 'La fecha es incorrecta.' y devuelve False

## Errores comunes

- Olvidar list(...) alrededor de filter o map: se obtiene un objeto <filter object ...> o <map object ...> y no los valores.
- Usar return o sentencias dentro de una lambda: solo admite una expresión; si la lógica crece, usar def.
- Olvidar from functools import reduce (en Python 3 no es una función incorporada) o llamar a reduce con una lista vacía sin valor inicial.
- Recorrer dos veces el mismo iterador: la segunda vez está vacío porque ya se agotó.
- Llamar a next() sobre una lista (no es un iterador, hay que usar iter()) o sobre un iterador agotado (StopIteration).
- Copiar del PDF palabras reservadas traducidas ([x para x en lista si ...]) o un punto sobrante tras print(...): provocan SyntaxError.
