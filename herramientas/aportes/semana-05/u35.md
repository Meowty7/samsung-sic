## Glosario
**Pandas**: biblioteca de código abierto de Python para operar, limpiar y analizar datos; se importa como `import pandas as pd`.
**Serie (Series)**: estructura unidimensional de pandas en la que cada dato tiene un índice asociado (relación 1:1).
**DataFrame**: estructura bidimensional de pandas formada por un índice y columnas; varias series con el mismo índice forman un DataFrame.
**Índice (index)**: etiquetas de una serie; por defecto enteros desde 0, o los nombres que se indiquen con el parámetro `index`.
**NaN**: valor que indica un dato faltante; aparece al operar series cuyos índices no coinciden.
**Gráfico lineal**: gráfico de matplotlib (`plt.plot`) que une puntos (x, y) con una línea.
**Gráfico de barras**: gráfico (`plt.bar` vertical, `plt.barh` horizontal) donde la altura o longitud de cada barra es proporcional al valor.
**Densidad de población**: número de habitantes por unidad de superficie, normalmente por km².

## Quiz
P: ¿Cuál es la diferencia principal entre una Serie y un DataFrame de pandas?
A) La Serie es bidimensional y el DataFrame unidimensional
B) La Serie es unidimensional y el DataFrame bidimensional
C) La Serie solo guarda texto y el DataFrame solo números
D) No hay diferencia, son nombres distintos del mismo objeto
Correcta: B
Por qué: la Serie tiene índice y datos (1D); el DataFrame tiene índice y columnas (2D).
Referencia: PDF parte 2, pág. 89

P: ¿Qué índice tiene `pd.Series({'Thor': 2013, 'Ultron': 2015})`?
A) 0 y 1
B) 2013 y 2015
C) 'Thor' y 'Ultron'
D) No tiene índice
Correcta: C
Por qué: al crear una serie desde un diccionario, las claves pasan a ser el índice y los valores los datos.
Referencia: PDF parte 2, pág. 99

P: ¿Cómo se selecciona de una serie `sr` (con índice 0 a 7) los elementos de las posiciones 4 y 5?
A) sr[4, 5]
B) sr[[4, 5]]
C) sr(4, 5)
D) sr{4, 5}
Correcta: B
Por qué: para seleccionar varios elementos se pasa una lista de índices entre corchetes dobles.
Referencia: PDF parte 2, pág. 110

P: Si `sr1 = pd.Series([10, 20, 30, 40, 50])` y `sr2 = pd.Series([23, 345, 123])`, ¿qué valores tiene `sr1 + sr2` en los índices 3 y 4?
A) 0
B) 40 y 50
C) NaN
D) Se produce un error
Correcta: C
Por qué: pandas empareja por índice y los elementos sin pareja quedan como NaN.
Referencia: PDF parte 2, pág. 113

P: Con la serie `sr3` del ejemplo anterior (33, 365, 153, NaN, NaN), ¿cuánto vale `sr3.count()`?
A) 5
B) 3
C) 2
D) 551
Correcta: B
Por qué: `count()` cuenta las observaciones no nulas; los dos NaN no se cuentan (551 es el resultado de `sum()`).
Referencia: PDF parte 2, pág. 115

P: ¿Qué función de matplotlib es adecuada para comparar los valores de muchas ciudades con nombres largos?
A) plt.plot()
B) plt.bar()
C) plt.barh()
D) plt.title()
Correcta: C
Por qué: el gráfico de barras horizontal muestra bien las diferencias entre variables con nombre; el vertical se reserva para series temporales.
Referencia: PDF parte 2, págs. 123 y 130

## Errores comunes
- Instalar pandas en un Python distinto del que ejecuta el código, lo que produce `ImportError`; hay que instalar dentro del entorno virtual activo.
- Crear una serie con un índice de longitud distinta a la de los datos (`ValueError`).
- Operar series con índices que no coinciden y no notar los `NaN` del resultado, que además convierten la serie a `float64`.
- Seleccionar varios elementos con `sr[4, 5]` en lugar de `sr[[4, 5]]`.
- Restar en el orden equivocado (`s_2020 - s_2021` da la variación con signo invertido) e interpretar mal el gráfico.
- Usar `max()` esperando el nombre de la ciudad: devuelve el valor; la etiqueta se obtiene con `idxmax()`.
