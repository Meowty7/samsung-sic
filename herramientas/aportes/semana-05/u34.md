## Glosario

**módulo**: archivo `.py` que agrupa funciones, clases y variables (y puede incluir código de ejecución); puede ser estándar o externo.
**módulo estándar**: módulo incorporado en Python que no requiere instalación, como `os`, `math`, `random` o `datetime`.
**módulo externo**: módulo creado por terceros que hay que instalar antes de usarlo, como `pandas`, `numpy` o `matplotlib`.
**pip**: herramienta que instala módulos externos desde PyPI con el comando `pip install nombre`.
**import / from / as**: sentencias para traer un módulo completo, solo algunos de sus nombres, o asignarles un alias.
**marca de tiempo Unix**: segundos transcurridos desde las 00:00:00 UTC del 1 de enero de 1970; la devuelve `time.time()` como `float`.
**timedelta**: objeto de `datetime` que representa una duración o la diferencia entre dos fechas; se suma y se resta con fechas.
**semilla (seed)**: valor inicial del generador aleatorio; con `random.seed(n)` la secuencia de números se repite igual.

## Quiz

P: ¿Cuál de estos módulos es un módulo externo que hay que instalar con pip?
A) math
B) random
C) pandas
D) datetime
Correcta: C
Por qué: math, random y datetime son módulos estándar incorporados en Python; pandas lo fabrica un tercero y debe instalarse.
Referencia: PDF parte 2, pág. 10

P: Después de ejecutar `from math import sin`, ¿qué ocurre al escribir `math.sin(1)`?
A) Devuelve 0.8414709848078965
B) Devuelve 1
C) Da NameError porque math no fue importado
D) Da ModuleNotFoundError
Correcta: C
Por qué: from trae solo el nombre sin; el nombre math no queda definido, así que se produce NameError.
Referencia: PDF parte 2, págs. 23–24

P: ¿Qué valores puede devolver `random.randint(1, 6)`?
A) Solo 2, 3, 4 y 5
B) Los enteros de 1 a 6, ambos incluidos
C) Los enteros de 1 a 5
D) Números reales entre 1 y 6
Correcta: B
Por qué: randint incluye ambos extremos (a <= N <= b), por eso sirve para simular un dado; la diapositiva del PDF que escribe a < N < b es incorrecta.
Referencia: PDF parte 2, pág. 32

P: ¿Qué hace `time.sleep(2)`?
A) Devuelve la hora actual
B) Pausa la ejecución durante 2 segundos
C) Cierra el programa en 2 segundos
D) Repite el bucle 2 veces
Correcta: B
Por qué: sleep detiene el hilo que la llama durante los segundos indicados (entero o float).
Referencia: PDF parte 2, pág. 33

P: ¿Cuál es el resultado de `datetime(2000, 5, 3) + timedelta(days=30)`?
A) 2000-06-02 00:00:00
B) 2000-06-03 00:00:00
C) 2000-05-30 00:00:00
D) 2000-07-03 00:00:00
Correcta: A
Por qué: del 3 de mayo, 28 días llegan al 31 de mayo y 2 más al 2 de junio; la suma de un timedelta a una fecha da otra fecha.
Referencia: PDF parte 2, pág. 46

P: ¿Qué mensaje indica normalmente que un módulo externo no está instalado en el entorno actual?
A) NameError
B) ModuleNotFoundError
C) ZeroDivisionError
D) SyntaxError
Correcta: B
Por qué: ModuleNotFoundError: No module named '...' significa que Python no encuentra el módulo en el entorno; se resuelve con pip install.
Referencia: PDF parte 2, pág. 18

## Cheatsheet

import math  # importa el módulo completo; se usa math.sin(1)
from math import floor, ceil  # trae solo funciones; floor(3.2) = 3, ceil(4.6) = 5
import math as m  # alias de módulo; m.sin(1)
from math import sin as s  # alias de una función; s(1)
pip install nombre  # instala un módulo externo desde PyPI
random.seed(34)  # fija la semilla para resultados reproducibles
random.randint(1, 6)  # entero de 1 a 6, ambos incluidos (un dado)
random.sample(lista, 3)  # 3 elementos distintos, sin repetición
random.choice(lista)  # un elemento al azar
time.sleep(0.5)  # pausa 0.5 segundos
time.strftime("%d/%m/%Y %H:%M", time.localtime())  # fecha y hora con formato
datetime.date.today()  # fecha actual
datetime.datetime.now()  # fecha y hora actuales
fecha + timedelta(days=30)  # fecha 30 días después
fecha.replace(month=12, day=30)  # copia con mes y día cambiados

## Errores comunes

- Olvidar instalar el módulo externo (o instalarlo en otro entorno virtual) y obtener `ModuleNotFoundError`.
- Escribir `import modulo.py` con la extensión: el módulo se importa sin `.py`.
- Usar `math.sin(1)` después de `from math import sin`: solo se trajo el nombre `sin`, no `math`.
- Creer que `randint(a, b)` excluye `b` (lo incluye) o que `randrange(a, b)` lo incluye (no lo incluye).
- Confundir `%m` (mes) con `%M` (minutos) en `strftime`, o dejar `%%` en el formato (imprime un `%` literal).
- Escribir los argumentos de `timedelta` en español; deben ir en inglés (`days`, `hours`, `weeks`).
