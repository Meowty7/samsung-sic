## Glosario

**algoritmo**: conjunto de instrucciones con una secuencia razonable que, a partir de una entrada, produce una salida para resolver un problema.
**pseudocódigo**: representación de un algoritmo en lenguaje cotidiano; sirve de puente entre el diagrama de flujo y el código real.
**diagrama de flujo**: representación gráfica de un algoritmo con formas normalizadas (ISO) y flechas que indican el flujo.
**EDP (proceso de diseño técnico)**: serie de etapas (definir, idear, prototipar, probar, mejorar) que siguen ingenieros y científicos para resolver un problema.
**búsqueda lineal**: algoritmo que revisa los datos uno a uno desde el principio; necesita n pasos en el peor caso.
**búsqueda binaria**: algoritmo que, sobre datos ordenados, compara con el centro y descarta la mitad; necesita log2 n pasos.
**notación Big O**: representación matemática de cómo crece el número de operaciones de un algoritmo según el número de datos.
**complejidad espacial y temporal**: medidas de rendimiento de un algoritmo; la primera mide la memoria usada y la segunda el número de pasos.

## Quiz

P: ¿Cuál es la sigla del proceso que siguen ingenieros y científicos para pasar de un problema a una solución, según el PDF?
A) EDP (proceso de diseño técnico)
B) ISO
C) CPU
D) PDF
Correcta: A
Por qué: el PDF llama a ese ciclo de definir, idear, prototipar, probar y mejorar "proceso de diseño técnico" (EDP).
Referencia: PDF semana 0, pág. 88

P: ¿Qué forma del diagrama de flujo se usa para bifurcar según una condición?
A) Óvalo
B) Rectángulo
C) Rombo
D) Flecha
Correcta: C
Por qué: el rombo es el símbolo de decisión y tiene salidas sí y no.
Referencia: PDF semana 0, pág. 95

P: ¿Para qué sirve el pseudocódigo?
A) Para ejecutarse directamente en Python
B) Como puente entre el diagrama de flujo y el código real
C) Para medir el tiempo de ejecución
D) Para instalar paquetes
Correcta: B
Por qué: el pseudocódigo describe en lenguaje cotidiano lo que hará cada línea y guía la escritura del código.
Referencia: PDF semana 0, pág. 94

P: Para buscar un dato entre 100, ¿cuántos pasos necesita aproximadamente la búsqueda binaria en el peor caso?
A) 100
B) 50
C) 25
D) 7
Correcta: D
Por qué: reduce el rango a la mitad en cada paso, log2 100 es aproximadamente 7.
Referencia: PDF semana 0, pág. 100

P: ¿Qué requisito tiene la búsqueda binaria?
A) Que los datos estén ordenados
B) Que haya menos de 10 datos
C) Que todos los datos sean iguales
D) Que los datos sean cadenas
Correcta: A
Por qué: solo se puede descartar una mitad si se sabe de qué lado están los valores mayores y menores.
Referencia: PDF semana 0, pág. 99

P: ¿Qué notación Big O corresponde a la búsqueda lineal y cuál a la binaria?
A) O(log n) y O(n)
B) O(n) y O(log n)
C) O(n^2) y O(n)
D) O(1) y O(n!)
Correcta: B
Por qué: la lineal crece proporcionalmente a n y la binaria crece de forma logarítmica.
Referencia: PDF semana 0, pág. 104

## Cheatsheet

for i, d in enumerate(datos):  # recorre índice y valor (búsqueda lineal)
centro = (inicio + fin) // 2  # posición central en la búsqueda binaria

fin = centro - 1  # descarta la mitad derecha

## Errores comunes

- Programar directamente sin planificar con pseudocódigo o diagrama de flujo.
- Usar búsqueda binaria en una lista sin ordenar.
- Pensar que Big O mide segundos en lugar de crecimiento del número de operaciones.
- Dibujar un rombo de decisión con una sola salida en lugar de sí y no.
- Confundir "PDE" (traducción errónea del PDF) con la sigla correcta EDP.
