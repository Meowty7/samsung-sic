## Glosario
- **iteración**: repetición de un bloque de código varias veces; también se llama bucle.
- **bucle for**: sentencia que repite un bloque una vez por cada elemento de una secuencia (`for variable in secuencia:`).
- **range**: función que genera enteros consecutivos con la forma `range(inicio=0, parada, paso=1)`; la parada se excluye.
- **variable de control del bucle**: variable (`i`, `j`, `k`) que toma un valor distinto en cada vuelta; se puede reemplazar por `_` si no se usa.
- **objeto secuencial**: objeto con varios elementos ordenados, como una lista o una cadena, que `for` puede recorrer.
- **acumulador**: variable inicializada antes del bucle y actualizada en cada vuelta (por ejemplo `s += i`).
- **sangría (indentación)**: espacios al inicio de las líneas que forman el bloque repetido del `for`.
- **bucle infinito**: iteración que nunca sale del círculo; no ocurre con `for` sobre una secuencia finita.

## Quiz
P: ¿Cuántas veces se ejecuta el bloque de `for i in range(5):`?
A) 4 veces
B) 5 veces
C) 6 veces
D) Infinitas veces
Correcta: B
Por qué: `range(5)` genera 0, 1, 2, 3, 4, es decir, cinco valores.
Referencia: PDF semana 0, pág. 439

P: ¿Qué valores recorre `range(1, 10, 2)`?
A) 1, 3, 5, 7, 9
B) 1, 2, 3, ..., 10
C) 2, 4, 6, 8, 10
D) 1, 3, 5, 7, 9, 10
Correcta: A
Por qué: empieza en 1, avanza de 2 en 2 y se detiene antes de la parada 10.
Referencia: PDF semana 0, págs. 443 y 480

P: ¿Qué ocurre al ejecutar `for i in range(0.9): print(i)`?
A) Imprime 0
B) No imprime nada
C) Lanza TypeError porque range no acepta números reales
D) Imprime 0.9
Correcta: C
Por qué: los argumentos de `range` deben ser enteros; el PDF muestra `'float' object cannot be interpreted as an integer`.
Referencia: PDF semana 0, pág. 444

P: Si se escribe `sum = 0` y luego `sum(range(1, 11))`, ¿qué ocurre?
A) Devuelve 55
B) Devuelve 0
C) Lanza TypeError: 'int' object is not callable
D) Lanza NameError
Correcta: C
Por qué: la variable `sum` oculta la función incorporada; se recomienda llamar `s` o `total` al acumulador.
Referencia: PDF semana 0, págs. 450–451

P: ¿Qué imprime `for ch in 'Hello': print(ch, end=' ')`?
A) Hello (en una línea sin espacios)
B) H e l l o (en una misma línea, separado por espacios)
C) Cinco líneas, una por letra
D) Un TypeError, porque una cadena no es una secuencia
Correcta: B
Por qué: `for` recorre la cadena carácter por carácter y `end=' '` evita el salto de línea.
Referencia: PDF semana 0, pág. 459

P: En el proyecto de combinaciones de alimentos hay 3 panes, 3 carnes, 3 verduras y 3 salsas. ¿Cuántas combinaciones imprimen los cuatro `for` anidados?
A) 12
B) 27
C) 64
D) 81
Correcta: D
Por qué: el bucle interno se ejecuta completo por cada valor del externo; el total es el producto 3 x 3 x 3 x 3.
Referencia: PDF semana 0, págs. 432–434

## Cheatsheet
for i in range(5):  # repite 5 veces con i = 0, 1, 2, 3, 4
for _ in range(10):  # repite 10 veces sin usar la variable
range(inicio, parada, paso)  # enteros desde inicio hasta parada-1 de paso en paso
list(range(0, 10, 2))  # [0, 2, 4, 6, 8]
range(1, 11)  # enteros del 1 al 10
range(10, 0, -1)  # cuenta regresiva del 10 al 1
for n in [11, 22, 33]:  # recorre una lista
for ch in 'Hello':  # recorre una cadena carácter por carácter
s = 0; for i in range(1, 11): s += i  # suma acumulada (55)
sum(numbers)  # suma los elementos de una lista sin bucle
fact = 1; for i in range(1, n + 1): fact *= i  # factorial de n
print(i, end=' ')  # imprime sin salto de línea
print('s', 'e', 'p', sep='-')  # imprime s-e-p
'{:5d}'.format(100)  # entero con 5 espacios de ancho
for b in panes: for m in carnes: print(b, m)  # bucles anidados: todas las combinaciones

## Errores comunes
- Creer que `range(10)` genera del 1 al 10: genera de 0 a 9 (para 1 a 10 se usa `range(1, 11)`).
- Olvidar los dos puntos al final del `for` o no sangrar el bloque (`SyntaxError` o `IndentationError`).
- Pasar números reales a `range` (`TypeError`); para reales existe `numpy.arange` (más adelante).
- Llamar `sum` a una variable y después intentar usar la función `sum()`.
- Inicializar el acumulador dentro del bucle (se reinicia en cada vuelta) o en 0 cuando se multiplica.
- Usar un paso negativo con inicio menor que la parada: el rango queda vacío.
