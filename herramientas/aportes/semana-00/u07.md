## Glosario
**if-else**: sentencia condicional doble: ejecuta el bloque del `if` si la condición es verdadera y el del `else` si es falsa.
**elif**: abreviatura de "else if"; examina otra condición solo cuando las anteriores fueron falsas.
**if anidado**: sentencia `if` o `if-else` escrita dentro del bloque de otra; cada nivel añade sangría.
**relación exclusiva**: relación entre dos condiciones que no pueden cumplirse a la vez.
**operador lógico**: `and`, `or` y `not`, que combinan valores booleanos en condiciones más complejas.
**módulo random**: módulo de Python para generar números aleatorios; se importa con `import random`.
**randint**: función `random.randint(a, b)` que devuelve un entero entre `a` y `b`, ambos incluidos.
**randrange**: función `random.randrange(n)` que devuelve un entero de 0 a `n - 1`.

## Quiz
P: ¿Cuándo se ejecuta el bloque de un `else`?
A) Siempre
B) Cuando la condición del `if` es verdadera
C) Cuando la condición del `if` es falsa
D) Solo si el `if` está anidado
Correcta: C
Por qué: `else` es el camino alternativo cuando la condición del `if` no se cumple.
Referencia: PDF semana 0, pág. 371

P: ¿Qué imprime este código?
num = 10
if num % 2 == 0:
    print("par")
else:
    print("impar")
A) impar
B) par
C) 10
D) Nada
Correcta: B
Por qué: `10 % 2` es 0, por lo que se ejecuta el bloque del `if`.
Referencia: PDF semana 0, pág. 375

P: En una cadena `if-elif-else`, ¿cuántos bloques se ejecutan como máximo?
A) Uno
B) Dos
C) Todos los que tengan condición verdadera
D) Ninguno
Correcta: A
Por qué: solo se ejecuta el bloque de la primera condición verdadera; el resto se omite.
Referencia: PDF semana 0, págs. 382–383

P: ¿Qué calificación imprime el generador del PDF para `score = 88`?
A) A
B) C
C) D
D) B
Correcta: D
Por qué: 88 no es 90 o más, pero sí es 80 o más, por lo que se asigna 'B'.
Referencia: PDF semana 0, págs. 390–392

P: ¿Qué devuelve `random.randrange(2)`?
A) Solo 1
B) 0 o 1
C) 1 o 2
D) Un decimal entre 0 y 2
Correcta: B
Por qué: `randrange(n)` devuelve un entero de 0 a `n - 1`; con `n = 2` son 0 y 1.
Referencia: PDF semana 0, págs. 414–415

P: ¿Cuál es la expresión correcta de año bisiesto?
A) year % 4 == 0
B) year % 100 == 0 and year % 400 == 0
C) (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
D) year % 4 == 0 or year % 100 != 0
Correcta: C
Por qué: es bisiesto si es divisible por 4 y no por 100, o si es divisible por 400 (1900 no lo es; 2000 sí).
Referencia: PDF semana 0, pág. 396

## Cheatsheet
if x > 0:  # primera condición
elif x == 0:  # se evalúa solo si la anterior fue falsa
else:  # se ejecuta si ninguna condición fue verdadera
if n % 2 == 0: print("par")  # decide par o impar
if a >= 0:  # if exterior; dentro puede haber otro if-else sangrado
a and b  # True solo si ambos son True
a or b  # True si alguno es True
not a  # invierte el valor booleano
(y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)  # año bisiesto
import random  # carga el módulo de números aleatorios
random.randint(1, 3)  # entero entre 1 y 3, ambos incluidos
random.randrange(2)  # devuelve 0 o 1
random.seed(7)  # fija la semilla (ampliación): resultados reproducibles
x in ('a', 'e', 'i', 'o', 'u')  # comprueba pertenencia a una tupla

## Errores comunes
- Escribir `if score > 90` cuando el enunciado dice "90 o más" (hace falta `>=`).
- Usar varios `if` sueltos cuando las condiciones son excluyentes y convendría `elif`/`else`.
- Poner las condiciones de un `elif` en orden incorrecto (por ejemplo, empezar por el límite más bajo).
- Dejar cadenas sin comillas en `print` o en asignaciones (`fruit = Manzana`).
- Comparar textos con distinta capitalización (`"Izquierda"` frente a `"izquierda"`).
- Llamar a `random.randint` sin haber escrito `import random`.
