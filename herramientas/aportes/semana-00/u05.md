## Glosario

**booleano**: tipo de datos con solo dos valores, `True` y `False`.
**operador de comparación**: compara dos valores y devuelve un booleano: `== != > < >= <=`.
**operador lógico**: combina booleanos: `and`, `or`, `not`.
**tabla de verdad**: lista el resultado de un operador lógico para todas las combinaciones de entradas.
**is**: operador de identidad; indica si dos nombres apuntan al mismo objeto.
**bool()**: función que convierte cualquier valor a booleano (0, `''`, `None` y `[]` dan `False`).
**precedencia**: orden en que se evalúan los operadores de una expresión; los paréntesis tienen la mayor.
**año bisiesto**: año de 366 días: divisible por 4 y no por 100, o divisible por 400.

## Quiz

P: ¿Qué devuelve `5 != 5`?
A) True
B) False
C) 0
D) Un error
Correcta: B
Por qué: `!=` es True solo si los valores son distintos; aquí son iguales.
Referencia: PDF semana 0, pág. 264

P: ¿Cuál de estos valores da `False` al convertirlo con `bool()`?
A) -1
B) 'hello'
C) [10, 20]
D) None
Correcta: D
Por qué: None, 0, la cadena vacía y la lista vacía son False; el resto de valores es True.
Referencia: PDF semana 0, pág. 266

P: Con `a = 1` y `b = 1.0`, ¿qué resultado dan `a == b` y `a is b`?
A) True y True
B) False y False
C) True y False
D) False y True
Correcta: C
Por qué: `==` compara valores (iguales) e `is` compara si son el mismo objeto (un int y un float no lo son).
Referencia: PDF semana 0, pág. 272

P: ¿Cuándo es `False` la expresión `x or y`?
A) Cuando alguno es False
B) Cuando ambos son False
C) Cuando ambos son True
D) Nunca
Correcta: B
Por qué: `or` solo es False si todas las entradas son False.
Referencia: PDF semana 0, págs. 277, 280

P: ¿Qué valor tiene `(x + y + z) / 3` frente a `x + y + z / 3` con 10, 20 y 30?
A) 20.0 y 40.0
B) 20.0 y 20.0
C) 40.0 y 20.0
D) 60 y 20.0
Correcta: A
Por qué: sin paréntesis se divide primero solo z entre 3, así que 10 + 20 + 10 = 40.0.
Referencia: PDF semana 0, pág. 293

P: ¿Qué fórmula decide si `year` es bisiesto?
A) year % 4 == 0 or year % 100 != 0
B) (year % 4 == 0 and year % 100 != 0) or year % 400 == 0
C) year % 400 == 0 and year % 4 == 0
D) year % 100 == 0 or year % 400 == 0
Correcta: B
Por qué: debe ser divisible por 4 y no por 100, o bien divisible por 400 (2000 sí, 1900 no).
Referencia: PDF semana 0, págs. 256, 260

## Cheatsheet

10 > 5  # True: comparación mayor que
5 != 5  # False: distinto de
a == b  # True si ambos valores son iguales
a is b  # True solo si son el mismo objeto
0 < n < 200  # comparación encadenada: n entre 0 y 200
'aaa' in 'aaa-bbb'  # True: la cadena está contenida
bool(0)  # False: el 0 es falso
bool('hello')  # True: cadena con contenido
x and y  # True solo si ambos son True
x or y  # True si al menos uno es True
not x  # invierte el valor booleano
n % 2 == 0  # True si n es par
n // 100 == 3  # True si la centena de n es 3
(x + y + z) / 3  # promedio: los paréntesis mandan
(y % 4 == 0 and y % 100 != 0) or y % 400 == 0  # año bisiesto

## Errores comunes

- Confundir `=` (asignación) con `==` (comparación).
- Escribir `=<` o `! =` en lugar de `<=` y `!=`: es `SyntaxError`.
- Creer que `bool(' ')` es False: solo la cadena vacía `''` lo es.
- Usar `is` para comparar números o textos en lugar de `==`.
- Olvidar paréntesis: `x + y + z / 3` no calcula el promedio.
- Mezclar `and` y `or` sin paréntesis: `and` se evalúa antes que `or`.
