## Glosario
**estructura secuencial**: forma de ejecución en la que los comandos se ejecutan uno tras otro, en el orden en que están escritos.
**estructura de selección**: estructura en la que se elige y ejecuta una de varias instrucciones según una condición.
**estructura de iteración**: estructura en la que se ejecuta repetidamente la misma orden.
**expresión condicional**: expresión que se evalúa como un valor booleano (`True` o `False`) y decide qué rama se ejecuta.
**bloque**: conjunto de líneas con sangría que se ejecutan cuando se cumple la condición de la sentencia que las encabeza.
**sangría**: espacios al inicio de una línea que indican a qué bloque pertenece; PEP-8 recomienda 4 espacios.
**pass**: sentencia que no hace nada; sirve como marcador de posición en un bloque vacío.
**separador**: carácter que `split()` usa para cortar una cadena en partes (por defecto, el espacio).

## Quiz
P: ¿Cuáles son las tres estructuras básicas de control de un programa?
A) Variable, función y clase
B) Secuencia, selección e iteración
C) Entrada, proceso y salida
D) Suma, resta y multiplicación
Correcta: B
Por qué: el PDF indica que todo programa se construye con secuencia, selección e iteración.
Referencia: PDF semana 0, pág. 316

P: ¿Qué imprime este código?
edad = 24
if edad < 20:
    print("descuento para jóvenes")
A) descuento para jóvenes
B) Nada
C) Un error de sintaxis
D) False
Correcta: B
Por qué: `24 < 20` es `False`, así que el bloque del `if` no se ejecuta.
Referencia: PDF semana 0, págs. 324–325

P: ¿Qué diferencia hay entre `=` y `==`?
A) `=` compara y `==` asigna
B) Son equivalentes
C) `=` asigna un valor y `==` compara dos valores
D) `==` solo funciona con cadenas
Correcta: C
Por qué: la asignación guarda un valor en una variable; el operador relacional devuelve `True` o `False`.
Referencia: PDF semana 0, pág. 347

P: ¿Qué error produce una línea con sangría distinta dentro de un mismo bloque?
A) NameError
B) ZeroDivisionError
C) TypeError
D) IndentationError
Correcta: D
Por qué: todas las líneas de un bloque deben tener el mismo número de espacios.
Referencia: PDF semana 0, págs. 326 y 350

P: ¿Qué expresión comprueba que `numero` es múltiplo de 3?
A) numero // 3 == 0
B) numero % 3 == 0
C) numero / 3 == 0
D) numero = 3
Correcta: B
Por qué: el operador `%` devuelve el resto; si es 0, la división entre 3 es exacta.
Referencia: PDF semana 0, pág. 332

P: ¿Qué devuelve `'10,20,30'.split(',')`?
A) ['10', '20', '30']
B) [10, 20, 30]
C) ['10,20,30']
D) '10 20 30'
Correcta: A
Por qué: `split` devuelve una lista de cadenas; para obtener enteros hay que aplicar `int()` a cada elemento.
Referencia: PDF semana 0, págs. 351–353

## Cheatsheet
if edad < 20:  # ejecuta el bloque si la condición es verdadera
    print("hola")  # bloque con sangría de 4 espacios
if x == 5:  # == compara; = asigna
n % 3 == 0  # True si n es múltiplo de 3
n % 2 == 0  # True si n es par
if a == 1 or a == 2:  # basta con que una condición sea verdadera
if n % 3 == 0 and n % 5 == 0:  # ambas condiciones deben cumplirse
s1 != s2  # True si las cadenas son diferentes
pass  # bloque vacío (marcador de posición)
texto.split()  # divide por espacios y devuelve una lista
texto.split(',')  # divide usando la coma como separador
int(x)  # convierte una cadena en entero
a, b, c = input().split()  # recibe tres valores separados por espacios
random.seed(42)  # fija la semilla del generador (ampliación)

## Errores comunes
- Olvidar los dos puntos al final de la línea del `if`.
- No sangrar el bloque o usar distinto número de espacios en sus líneas (`IndentationError`).
- Escribir `if x = 5:` en lugar de `if x == 5:`.
- Dejar un bloque vacío sin `pass`.
- Operar con lo que devuelve `input()` sin convertirlo con `int()`.
- Usar el separador equivocado en `split()` (por ejemplo, comas cuando la entrada va separada por espacios).
