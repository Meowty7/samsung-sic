## Glosario
- **cola (queue)**: tipo de dato abstracto en el que se añade por la parte trasera y se elimina por la parte delantera.
- **FIFO**: First-In-First-Out; el primer elemento que entra es el primero que sale.
- **enqueue**: operación que añade un elemento al final (parte trasera) de la cola.
- **dequeue**: operación que elimina y devuelve el elemento del frente de la cola; devuelve None si está vacía.
- **tipo de dato abstracto (ADT)**: descripción de una estructura por sus operaciones, independiente de cómo se implemente.
- **problema de Josefo (Josephus)**: N personas en círculo; se elimina cada K-ésima hasta que queda una; se pide el orden de eliminación.
- **deque**: cola de doble extremo; permite añadir y eliminar por ambos lados.

## Cheatsheet
cola = []  # cola vacía con una lista
cola.append(x)  # enqueue: añade al final
cola.pop(0)  # dequeue: saca el primero (frente)
len(cola) == 0  # is_empty: comprueba si está vacía
q = Queue()  # crea una instancia de la clase Queue
q.enqueue("A")  # añade "A" a la cola
q.dequeue()  # devuelve y elimina el frente; None si está vacía
q.is_empty()  # True si no hay elementos
q.size()  # cantidad de elementos (len(self.queue))
j % k == 0  # condición del K-ésimo en el problema de Josefo
sequence.append(queue.dequeue())  # añade el último sobreviviente a la secuencia
from collections import deque  # cola eficiente de la biblioteca estándar
fila.popleft()  # dequeue eficiente con deque

## Errores comunes
- Usar pop() en lugar de pop(0) en dequeue: se obtiene el comportamiento de una pila (LIFO).
- Llamar a queue.size() sin haber definido el método size() en la clase.
- No incrementar el contador j en cada vuelta del bucle de Josefo.
- Usar el resultado de dequeue() sin comprobar si es None cuando la cola puede estar vacía.
- Confundir pila y cola por las traducciones del PDF: títulos que dicen "pila" y comentarios que dicen "clase stack" en la unidad de cola.
