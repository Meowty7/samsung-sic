## Glosario

- **búsqueda secuencial**: algoritmo que revisa los elementos de una lista uno por uno, en orden, hasta encontrar el valor buscado o agotar la lista.
- **problema de búsqueda**: tarea de encontrar la posición de un elemento específico dentro de unos datos dados, o determinar que no existe.
- **tiempo lineal**: complejidad O(n); el número de operaciones crece en proporción al tamaño de los datos.
- **caso base (mejor caso)**: situación en que el elemento buscado es el primero y basta una sola comparación, O(1).
- **peor caso**: situación en que el elemento no existe y se comparan los n elementos, O(n).
- **valor centinela**: valor especial, como -1, que indica "no encontrado" porque no es un índice válido.
- **find_largest**: función que encuentra el índice del mayor elemento recorriendo la lista una sola vez y guardando el índice del mayor visto hasta el momento.
- **rotura (breaking)**: en el problema de la caída de huevos, el piso más bajo desde el cual el huevo se rompe.

## Quiz

P: ¿Qué devuelve `seq_search(nums, x)` cuando `x` no existe en `nums`?
A) 0
B) None
C) -1
D) len(nums)
Correcta: C
Por qué: el algoritmo recorre toda la lista y, si no hubo coincidencias, devuelve -1 como valor que indica "no encontrado".
Referencia: PDF parte 1, pág. 148

P: Para una lista de N elementos, ¿cuántas comparaciones se hacen en promedio al buscar cada elemento una vez con la búsqueda secuencial?
A) N
B) (N + 1) / 2
C) log2(N)
D) 1
Correcta: B
Por qué: la suma 1 + 2 + ... + N es N(N + 1) / 2; dividida entre N da (N + 1) / 2, que es O(n).
Referencia: PDF parte 1, pág. 150

P: Con `nums = [11, 37, 45, 26, 59, 28, 17, 53]`, ¿qué devuelve `find_largest(nums)`?
A) 59
B) 4
C) 7
D) 0
Correcta: B
Por qué: devuelve el índice del mayor elemento; 59 está en la posición 4.
Referencia: PDF parte 1, pág. 151

P: ¿Qué imprime `print(nums[i], nums[j])` tras `i, j = find_two(nums)` con la lista anterior?
A) 11 59
B) 59 53
C) 37 11
D) 59 11
Correcta: D
Por qué: `find_two` guarda en `x` el índice del mayor y en `y` el del menor, así que se imprimen 59 y 11 en un solo recorrido.
Referencia: PDF parte 1, pág. 172

P: En el problema de la caída de huevos con un huevo, si el edificio tiene 10 pisos y el huevo se rompe desde el piso 6, ¿cuál es el piso más alto seguro?
A) 6
B) 4
C) 5
D) 10
Correcta: C
Por qué: si el experimento falla en el piso n, el resultado es n - 1; es decir, 5.
Referencia: PDF parte 1, págs. 134–136

P: Según el PDF, ¿cuál es el número mínimo de experimentos en el peor caso con dos huevos en un edificio de 100 plantas?
A) 14

## Cheatsheet

```python
x in S                      # True si x está en la lista (búsqueda secuencial integrada)
S.index(x)                  # posición de la primera coincidencia; ValueError si no existe
for i in range(len(S)):     # recorre los índices de la lista
if x == S[i]: return i      # coincidencia: devuelve el índice y termina
return -1                   # tras el bucle: no se encontró x
largest = 0                 # el primer elemento se supone el mayor
for i in range(1, len(S)):  # compara desde el segundo elemento
if S[largest] < S[i]: largest = i   # actualiza el índice del mayor
S[largest]                  # valor del mayor elemento
randint(1, height)          # entero aleatorio entre 1 y height (módulo random)
floor >= breaking           # True si el huevo se rompe desde ese piso
return n - 1                # piso más alto seguro cuando se rompe en el piso n
frase.split()               # lista de palabras separadas por espacios
```

## Errores comunes

- Colocar `return -1` dentro del bucle: debe ir después, cuando ya se revisaron todos los elementos.
- Confundir el índice del mayor con el valor del mayor: `find_largest` devuelve el índice.
- Llamar a `find_largest` con una lista vacía: `nums[0]` lanza `IndexError`.
- Devolver `n` en lugar de `n - 1` en el problema de los huevos: el piso donde se rompe no es el piso seguro.
- Creer que la búsqueda secuencial necesita datos ordenados; no los necesita.
